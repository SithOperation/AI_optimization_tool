# Privacy

AI Optimization Tool does not require prompt or response content for core usage, cost, forecasting, or optimization analytics.

Defaults on: token counts, model, provider, latency, application/workload metadata, and cost metadata. Defaults off: prompt content, response content, and direct user identity. Setup can finish with content disabled; core processing remains local and paid integrations are optional.

TokenScope processes telemetry locally and does not phone home. Content collection is not implemented in Milestone 1. Identity mode defaults to `anonymous`; no identity field is required for analytics.
